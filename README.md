# Homebrew Tap for EasyCLIProxyAPI

Personal Homebrew tap for [router-for-me/EasyCLIProxyAPI](https://github.com/router-for-me/EasyCLIProxyAPI).

## Install

```sh
brew install --cask aboutdomtime/easycliproxyapi/easycliproxyapi
```

Seeded from upstream release `v0.2.23`.

## Updating

`.github/workflows/update-cask.yml` checks the latest upstream GitHub release every six hours and commits cask version and SHA256 updates when a new release is available. It can also be run manually.
